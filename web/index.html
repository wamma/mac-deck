연결 및 사용 안내

웹 절전

검정 화면에서 첫 터치 또는 키는 복귀에만 사용합니다. 절전 중 이 기기의 상태 조회와 태블릿 알림은 중지됩니다. 맥 알림은 유지됩니다. OS가 화면을 끄면 기기 깨우기·잠금해제가 필요합니다. 화면 전원 OFF나 항상 켜짐을 보장하지 않습니다.

아이패드에서 연결

기본 서버 주소는 맥 전용입니다. README대로 LAN TLS를 설정하고 인증서가 정상 신뢰되는 주소를 Safari에서 연 뒤, 맥 콘솔에서 p를 입력해 열린 시간 안에 코드를 입력하세요. Safari 공유 메뉴에서 ‘홈 화면에 추가’하면 앱처럼 사용할 수 있습니다.

단축키 권한

맥의 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 서버를 실행한 Terminal 또는 Orca를 허용하세요. 네이티브 도우미 deck-bridge의 권한도 확인하세요. 허용 표시만으로 입력이 보장되지는 않으며 실제 활성 창을 조회한 뒤 전송합니다.

클립보드와 연결

클립보드는 수집을 켠 뒤 변경된 일반 텍스트를 최대 100개 보관합니다. 10만 자 초과·이미지·파일은 지원하지 않습니다. 기록은 서버 종료 시 삭제됩니다. 서버와 맥이 켜져 있어야 합니다. LAN에서는 신뢰된 HTTPS를 사용하세요. 명시적 HTTP 호환 모드는 암호화되지 않습니다.

원본의 AI 계기판

Codex 로컬 세션 작업 이벤트와 계정 한도를 읽습니다. Claude는 프로젝트의 hook/statusLine 연결을 사용합니다. 승인 신호나 창 연결을 증명하지 못하면 응답 키를 차단합니다. 회색은 미등록 또는 신호 없음이며 위치를 선택하면 Open-Meteo 날씨를 조회합니다.

Orca가 제공한 활동 정보입니다. 터미널 창·Codex/Claude 논리 세션 연결을 확인하지 않아 캡처와 키 응답은 제공하지 않습니다.
